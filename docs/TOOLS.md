# contractcraft MCP tools

Generated by `contractcraft tools --markdown`. Do not edit by hand: a test fails when this file
is out of date. Every tool is also a CLI verb (`contractcraft --help`). Dotted names (`app.verb`) are accepted.

| Tool | What it does | Required | Optional |
|---|---|---|---|
| `contract_status` | Counts by status, templates, sealed contracts, whether the seal key exists. | - | - |
| `contract_template_add` | Add a template (or a new version of it). Placeholders {{name}} must match the declared variables exactly. | `name` | `body`, `body_path`, `description`, `variables` |
| `contract_template_list` | Templates (latest versions) with their variables. | - | - |
| `contract_template_show` | One template with body and variables. | `name` | `version` |
| `contract_draft` | Create a draft from a template (values fill its variables; typos and missing required values are errors) or from your own text. Returns a quick risk count. | `title`, `counterparty` | `body`, `body_path`, `template`, `values` |
| `contract_list` | Contracts with status, allowed next statuses and the next deadline. | - | `status`, `text` |
| `contract_show` | One contract: text (current or a version), versions, status history, seals, risk findings, next deadline. | `contract` | `as_of`, `version` |
| `contract_edit` | New text version (draft only). Returns the redline stats and risk delta. | `contract` | `body`, `body_path`, `note` |
| `contract_terms` | Term data for deadlines: start, initial_months, renewal_months (0 = fixed term), notice_months, annual_value. Fixed after execution. | `contract` | `annual_value`, `initial_months`, `notice_months`, `renewal_months`, `start` |
| `contract_transition` | Move along draft -> under_review -> pending_signature -> executed -> terminated/expired (cancelled from any open state). Executing needs a seal of the current version and sends contract.executed to gaincraft. | `contract`, `to` | `note` |
| `contract_seal` | Seal the current version: SHA-256 of the text + Ed25519 signature. Tamper evidence, not a legal e-signature. | `contract` | - |
| `contract_verify` | Check all seals against the stored text; with path, check that a file is byte-identical to the sealed text. | `contract` | `path` |
| `contract_redline` | Line diff between two versions (default: previous vs current) plus which risk findings were added or removed. | `contract` | `from`, `to` |
| `contract_risk_scan` | Deterministic DE/EN clause scan (liability, indemnity, auto-renewal, foreign venue/law, missing DPA, penalties, unilateral changes, exclusivity). Optional TOML rule file. Not legal advice. | - | `contract`, `rules_path`, `text`, `version` |
| `contract_render` | Write the text as md (byte-identical to the sealed text), typ (Typst source) or pdf (needs the Typst CLI; fails clearly without it). | `contract`, `path` | `format`, `version` |
| `contract_deadlines` | Notice deadlines and term ends of executed contracts within N days (default 90). emit=true sends each once to taskcraft as contract.deadline. | - | `as_of`, `emit`, `within_days` |
| `contract_demo_seed` | Fill an EMPTY database with labelled demo templates and three contracts (executed, risky draft, renegotiated). | - | - |
