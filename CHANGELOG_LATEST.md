# contractcraft v0.2.0

Contract drafts, risk rules, and an integrity seal. Not a qualified signature. Local, one SQLite file. Windows x64.

## Downloads

- `contractcraft-app.exe`: the desktop window.
- `contractcraft.exe`: CLI and MCP server.
- `contractcraft-0.2.0-setup.exe`: per-user installer.
- `contractcraft-v0.2.0.mcpb`: MCP bundle.

## What is new

- A `candidate.hired` event from hirecraft opens one contract draft.
- Desktop window on the shared suite frame, with the pipeline board and seal checks.
